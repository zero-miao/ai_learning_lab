## 产品定位

一句话定位：**让用户一想到要学习，就会想把资料交给它。**

核心目标：**让学习自然而然地发生。** 产品不应只做“资料管理”或“AI 总结”，而应降低用户从产生学习意图到真正开始学习的阻力。用户可以有材料、有标题，或只有一个想学的话题；系统都应提供自然入口，并帮助用户判断、组织、学习、验证和复习。

| 进入场景 | 用户状态 | 产品路径 |
| --- | --- | --- |
| 场景一 | 有材料，想系统学 | 导入材料，建/选学习话题，开始学习。 |
| 场景二 | 有标题，先评估再决定 | 创建讨论话题；围绕话题和已有材料，AI 辅助用户生成摘要、判断与现有知识的关联度，并决定是否转为学习型话题。 |
| 场景三 | 有话题，不知从哪开始 | 新建讨论话题，由 AI 生成学习路线并推荐材料。 |

## 主页设计

主页回到最小入口：展示话题列表，支持搜索并进入话题；页面只保留一个主按钮“新建话题”。这样可以避免用户在“导入材料、创建主题、开始对话、查看笔记”之间迷路，让所有学习资产都回到话题。

话题列表顶部增加视图切换 Tab：**全部 / 学习 / 讨论**。默认展示全部话题；切到学习或讨论时，仅展示对应类型的话题，帮助用户区分“已经进入系统学习的内容”和“还在判断是否值得学的内容”。

**新建话题表单。** 表单包含三个字段：话题类型选择，支持“学习 / 讨论”；初始材料，可选，支持 URL 或文件；学习目标，由用户填写。初始材料不是创建话题的前置条件，用户只有一个想法时也可以先进入讨论型话题。

## 话题类型

V1-alpha 将话题分为讨论型和学习型。讨论型对应场景二、场景三的前置阶段，学习型对应场景一，以及讨论型完成判断后一键转化后的系统学习阶段。

### 讨论型话题

讨论型话题的目标是回答“应不应该学”，帮助用户在精力有限的情况下走对路。初始材料可选；无材料时 AI 基于模型知识与用户对话，有材料时 AI 阅读材料后参与对话。AI 的职责不是直接生成课程，而是帮助用户明确为什么学、为什么现在学、和已有知识有什么关系，以及是否值得投入系统学习。

讨论型话题的页面布局采用左右结构：左侧主体是对话流和输入框，承载用户与 AI 的自由对话；右侧是固定材料面板，展示当前话题材料列表，支持折叠，避免材料信息挤占主对话空间。右侧材料面板提供“+ 导入材料”按钮，允许用户在讨论过程中补充材料；创建话题时初始材料可选，不要求用户先准备材料。

进入讨论型话题后，AI 需要主动开场。有材料时，AI 先给出材料摘要、与已有知识的关联度判断（高 / 中 / 低），再抛出一个开放性问题，帮助用户判断是否值得继续学习。无材料时，AI 基于话题名称引导用户说明学习动机，或先给出该话题的核心价值和建议学习路径，帮助用户从“想学但不知道从哪开始”进入可讨论状态。

用户和 AI 可以自由对话，但 AI 始终围绕“要不要学、怎么开始”推进，而不是直接把讨论型话题变成完整课程。底部随时提供“转为学习型话题”按钮；用户不需要等待 AI 完成某个固定评估流程，只要自己判断要系统学习，就可以立即转换。

当用户决定要系统学习时，讨论型话题应支持一键转为学习型话题。转换后，已有对话、材料、判断依据和学习目标应进入学习型话题上下文，而不是丢弃重来。

### 学习型话题

学习型话题承载完整学习闭环：导入材料，进入阅读；在阅读中发现概念、建立关系、随时问答；遇到未知时补充材料；过程中持续查看和编辑话题思维导图；阶段性生成总结；最后通过验证考试和复习巩固。学习型不是“读完生成一篇笔记”，而是围绕一个话题持续增长知识结构。

学习型话题需要明确展示学习产出，而不是强调“生成结构化笔记”这个单一动作。话题学习产出包括：概念数量和思维导图入口、问答数量、总结（阶段 / 全局）、思维导图节点数。原“生成结构化笔记”按钮移除；结构化结果应从概念、问答、总结和思维导图的持续沉淀中自然形成。

## 学习主线（学习型话题）

学习型话题的主线从阅读体验开始。阅读材料是地基；如果阅读体验不好，后续概念卡片、问答、总结和思维导图都会变成悬空的 AI 产物。

1. 进入学习型话题。
2. 阅读材料，阅读体验作为学习链路的地基。
3. 概念发现：选中材料片段后标记为概念，AI 补全概念卡片，包括定义、原理、易错点、适用场景，并带材料锚点。
4. 关系建立：概念之间建立关系，支持跨材料、跨话题；AI 推荐关系，用户确认或调整。
5. 问答沉淀：用户随时提问，AI 基于当前材料或整个话题回答，回答可以存入概念或材料问答记录。
6. 遇到未知时补充材料，支持手动或自动补充，然后继续学习。
7. 随时查看和编辑话题思维导图；思维导图是过程视图，不是最后才生成的产物。
8. 阶段总结或全局总结写入话题。
9. 验证考试，覆盖概念解释、问答和测验题。
10. 通过话题思维导图快速复习，节点可跳回原文锚点。

**概念特性。** 同一话题下不同材料中的同一概念，应关联到同一节点，不重复新建。整个话题只有一张思维导图，思维导图关系由 AI 自动生成，用户可调整。跨话题关系可作为 P1 能力纳入，但 V1-alpha 首先要保证单话题内的概念共享和主图稳定。

## 阅读器方案

阅读器采用“组合式 UniversalReader”，按内容类型分发到不同组件。外层统一承载阅读布局、选择、高亮、锚点、AI 侧边栏和任务状态；内层按内容类型选择最适合的渲染组件。

| 内容类型 | 组件 |
| --- | --- |
| Markdown / 文章 | Milkdown 或 MDXEditor |
| HTML / 网页正文 | trafilatura 清洗 + 自定义沉浸式阅读视图 |
| PDF | React PDF Viewer / react-pdf |
| 视频 / 音频 | Vidstack Player |

**关键体验要求。** 阅读器需要保证字体清晰、行距舒适、阅读宽度合理、暗色模式、滚动顺滑、文本选择准确、锚点可靠。文本选择和锚点可靠性直接影响概念发现、问答沉淀和节点回跳，不能只按视觉效果验收。

### 选中文本交互（阅读视图）

阅读视图中，用户选中文本后浮出操作菜单。菜单提供三个动作：标记为概念、发起问答、高亮。三个动作代表不同强度的学习意图：标记为概念会进入知识沉淀，发起问答会进入理解澄清，高亮只做视觉标记和稍后处理。

**标记为概念。** 用户选中文字后选择“标记为概念”，AI 自动补全概念卡片，卡片内容包括定义、原理、易错点和适用场景。补全结果必须带来源锚点，明确来自哪篇材料、哪一段。该概念自动加入当前话题的概念池，并可从概念卡片侧栏执行“加入思维导图”，使概念进入话题主图。

**发起问答。** 用户选中文字后选择“发起问答”，选中文本作为问题上下文，用户再输入具体问题。AI 可以基于当前材料回答，也可以在用户选择或上下文需要时基于整个话题回答。回答结果可保存到对应概念，或保存到该材料的问答记录中，方便后续复盘。

**高亮。** 用户选中文字后选择“高亮”，系统只做纯视觉标记，不触发 AI。高亮用于“稍后处理”，用户可以在侧栏高亮列表查看所有高亮片段，再决定是否转为概念、提问或删除。

## 学习材料来源标注

每条学习材料都需要标注来源类型，至少区分“人工添加”和“AI 推荐”两种 tag。人工添加表示材料由用户主动导入或上传；AI 推荐表示材料由系统根据话题、学习目标、讨论内容或缺口判断推荐。该标注应展示在材料列表和材料详情入口附近，帮助用户理解材料来源，也方便后续评估推荐质量。

## 结构化笔记与概念思维导图 User Story

以下 User Story 保留此前已写入的设计，并与本轮“学习主线”和“话题学习产出”对齐。V1-alpha 的结构化笔记以概念节点、材料问答、阶段总结和 Topic 级思维导图为核心，Markdown 草稿不是首版主动作入口。

| 场景 | User Story | 验收标准 |
| --- | --- | --- |
| 阅读中添加概念 | **As a** 学习者，**I want** 在阅读材料时遇到新概念就能立即添加概念卡片，并让 AI 基于当前位置自动补全定义、原理、易错点和适用场景，**So that** 我可以在理解发生的现场沉淀知识，而不是读完后再凭记忆整理。 | 用户可从选中材料片段创建概念；概念自动关联 Topic、Material、MaterialChunk 和原文位置锚点；AI 补全内容至少包含定义、原理、易错点和适用场景；AI 补全结果进入草稿态，用户可编辑、确认或重新生成。 |
| 阅读中提问 | **As a** 学习者，**I want** 阅读时对不理解的内容直接提问，并让问题和回答保留材料位置锚点，**So that** 我后续复盘、生成思维导图或考试时能回到当时的真实疑问。 | 用户可从材料片段发起问题；AI 回答必须基于当前材料或话题上下文，并保存对应位置锚点；问题可关联到已有概念，或在必要时转为新概念；问题和回答可进入后续概念卡片、思维导图、应用任务和考试上下文。 |
| 生成 Topic 思维导图 | **As a** 学习者，**I want** 在学习过程中持续生成整个 Topic 的汇总思维导图，节点是概念，边是概念之间的关系，**So that** 我能看到这个话题的知识结构，而不是只保存一堆线性笔记。 | 系统基于当前 Topic 下的全部材料、概念卡片和关键问答生成一张主思维导图；思维导图节点对应概念，边对应概念间关系，并包含关系说明；一个 Topic 只有一张主思维导图，不按材料拆分多张图；用户可编辑节点、关系、关系说明和展示顺序。 |
| 概念节点回跳原文 | **As a** 学习者，**I want** 点击思维导图节点时展开概念详情，并能跳回材料中的原始位置，**So that** 我可以在结构化理解和原文证据之间来回切换。 | 点击节点后展示概念定义、原理、易错点、适用场景、关联问题和来源片段；概念详情提供跳回材料原始位置的入口；同一概念有多个来源时，应展示多个材料位置锚点；原文位置失效时，应提示来源不可用，而不是静默丢失。 |
| 跨材料共享概念 | **As a** 学习者，**I want** 同一 Topic 下不同材料遇到的同一概念关联到同一个节点，**So that** 我能持续丰富同一个概念，而不是在多篇材料里产生重复、割裂的笔记。 | 新增概念时，系统应在当前 Topic 内检索疑似同名或近义概念；发现疑似重复时，用户可选择合并到已有概念或创建新概念；合并后概念保留多个材料来源和位置锚点；思维导图中同一概念只出现一个主节点，可展开查看不同材料来源。 |

## 阶段计划

| 阶段 | 重点 | 验收标准 |
| --- | --- | --- |
| 阶段 1 | 主页重构 + UniversalReader 外壳 + HTML 阅读体验优化 + 原型对齐 | 材料导入后，阅读体验明显优于普通网页；主页只有话题列表和新建按钮，并支持“全部 / 学习 / 讨论”切换；V1-alpha 原型 v2 可作为验收参考。 |
| 阶段 2 | 选中文本操作 + 概念发现 + 概念卡片 | 阅读中选中文本后浮出操作菜单，可标记为概念、发起问答或高亮；概念卡片带来源锚点。 |
| 阶段 3 | 问答 + 沉淀 + 高亮列表 | 用户可以边读边问，有价值回答能存入概念或材料问答记录；高亮可作为稍后处理列表查看。 |
| 阶段 4 | 概念关系 + 话题思维导图 + 学习产出展示 | 话题形成可增长的知识地图，节点可回跳原文；话题页展示概念数量、问答数量、总结和思维导图节点数。 |
| 阶段 5 | 讨论型话题 + 快速评估 + 学习路线 | 三个进入场景全部闭环；讨论型话题采用左侧对话、右侧材料面板，并可随时转为学习型话题。 |
| 阶段 6 | 验证 + 复习闭环 | 可出题自测，可用思维导图快速复习。 |

## 技术约束与实现原则

实现上继续保持本地 Web 站点和单体应用边界，不优先考虑公网部署、多用户、鉴权、HTTPS、云备份或多租户。后端继续复用 Django、DRF、SQLite、APScheduler、AI Gateway 和 AITask 模式；长耗时 LLM 调用继续通过持久化任务和后台 worker 执行。前端优先复用 Ant Design、Axios 和现有异步任务轮询逻辑，避免为单个页面写一套特殊状态机制。

涉及 AI 输出的地方必须保留材料锚点，并区分材料事实、AI 解释和用户确认内容。概念、问答、总结、考试和复习都应回到 Topic，而不是散落在页面局部。高亮不触发 AI，避免把“稍后处理”的轻量动作误处理成知识沉淀。

## 验收标准

| 验收维度 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 入口完整性 | 用户可以从有材料、有标题、只有话题三种状态进入产品。 | 分别构造三个入口场景做端到端手工验收。 |
| 主页视图切换 | 话题列表顶部提供“全部 / 学习 / 讨论”Tab，并能按话题类型筛选。 | 创建学习型和讨论型话题，验证三个 Tab 下展示结果正确。 |
| 阅读体验 | UniversalReader 能稳定展示 HTML、Markdown、PDF、音视频中已纳入首版的内容类型，并保证选择、高亮和锚点可靠。 | 用真实文章和长网页验证阅读、选择、跳转和暗色模式。 |
| 选中文本操作 | 选中文本后浮出操作菜单，支持“标记为概念 / 发起问答 / 高亮”。 | 在阅读视图中选中文本，分别验证三个动作的结果和数据沉淀位置。 |
| 概念沉淀 | 用户可从选中文本创建概念卡片，概念带来源锚点，且同一话题内同一概念不重复创建。 | 在同一 Topic 导入两份材料，验证概念合并与多来源展示。 |
| 讨论型话题交互 | 讨论型话题左侧为对话流和输入框，右侧为可折叠材料面板；AI 能根据有无材料主动开场。 | 创建无材料讨论型话题和有材料讨论型话题各一例，验证开场内容、材料面板和对话推进方向。 |
| 讨论到学习转换 | 讨论型话题底部随时可点“转为学习型话题”，转换后保留上下文。 | 在 AI 未给出最终评估前点击转换，验证对话、材料、判断依据和学习目标进入学习型话题。 |
| 学习材料来源 | 每条材料展示“人工添加”或“AI 推荐”tag。 | 手动导入材料和使用 AI 推荐材料各一条，验证 tag 展示正确。 |
| 话题学习产出 | 学习型话题展示概念数量、思维导图入口、问答数量、总结和思维导图节点数，且没有“生成结构化笔记”按钮。 | 完成一次概念、问答、总结和思维导图操作后，检查话题页产出展示。 |
| 话题思维导图 | 一个 Topic 只有一张可增长思维导图，节点可回跳原文。 | 验证节点详情、关系编辑和原文锚点跳转。 |
| 原型对齐 | V1-alpha 原型 v2 的页面、颜色标注和核心交互与文档一致。 | 打开在线预览或本地 `output/v1-alpha-prototype-v2.html`，逐项核对新增功能与变更功能。 |

## 决策记录

| 决策项 | V1-alpha 结论 | 影响范围 |
| --- | --- | --- |
| 外部搜索 | V1-alpha 阶段暂不接入外部搜索引擎。学习材料来源限定为用户手动导入，或 AI 基于话题、学习目标、讨论内容和缺口判断给出的推荐材料。 | 材料导入、AI 推荐、学习路线生成 |
