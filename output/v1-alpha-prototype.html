PROTOTYPE OVERVIEW

V1-alpha 做完之后，界面会变成什么样

这是一份黑白线框原型，用于预览 V1-alpha 完成后的界面形态。线框沿用 MVP 的 Ant Design 布局语言（Layout / Card / List / Tag / Descriptions / Drawer / Result 等），仅用灰阶表达；蓝色标注代表相对 MVP 的新增，橙色标注代表变更。真实实现仍是 React + TypeScript + Vite + Ant Design 本地单页应用，接口沿用 AITask「发起→轮询」异步契约。

新增 New

MVP 中不存在的页面或组件。例如查资料与补证、微应用练习、笔记模板选择、统一任务状态组件。

变更 Changed

MVP 已有、但本轮结构或交互被改造。例如主题详情加阶段总览、阅读页前导前置、考试草稿保存、复习先答后评。

沿用 Keep

基本保持 MVP 形态，仅做细节适配。例如主题列表、顶部导航、整体路由结构。

学习主线：从「单材料闭环」升级为「多材料 + 应用检验」
进入主题→ 导入主线材料→ 前导前置阅读→ 划词提问 · 发起补证→ 模板化结构笔记→ 微应用作答→ 综合考试（可暂存）→ 复习先答后评

高亮环节即 V1-alpha 新增 / 变更的关键触点，所有 AI 产物都回流到「主题」对象，而不是散落在页面局部。

新增 / 变更标注（对应四个用户改进点）

  • 1AI 前导前置（改进点④，变更）：前导从右侧对话框移到正文首屏，作为阅读入口；长前导默认可折叠，保留重新生成与跳转能力，视觉上与正文区分但不压过正文。
  • 2保留引用链接（改进点③，变更）：导入从「纯文本」升级为「正文 + 链接元数据」，正文内 anchor 文本与外链按原始顺序保留并以链接样式展示，作为补证/笔记/出题的来源锚点。
  • 3难度档位（改进点②，变更）：新增「学习者友好 / 贴近原文」等档位，默认生成面向学习者的解释版而非高密度摘要，降低阅读负担。
  • 4保真标记（改进点②，变更）：段落标注「原文事实 / AI 解释 / 待确认」，避免把 AI 推断当成原文事实。
  • 5就地发起补证（新增，P0）：在问答气泡内直接把当前疑问带入补证流程，衔接「查资料与补证」页。
